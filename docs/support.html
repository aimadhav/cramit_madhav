Beta support

Something not sticking?

Tell us what happened and we’ll help. For beta issues, include your phone model, Android version, Cramit version and the screen where the problem appeared.

Never include passwords or tokens.

Screenshots are helpful, but remove private email addresses, notes and class codes first.

Email beta supportOpen GitHub issues

Before reporting

  1. Check that you are using the latest GitHub beta release.
  2. Try the action once on a stable network.
  3. If the app is offline, keep it installed so unsynced progress is not lost.
  4. Do not clear app storage until support confirms your cloud data is current.
